# Google Docs Inspiration

Patterns worth borrowing. Not a feature list; take only what fits the time box.

## Documents home

- Grid or list of documents sorted by last modified, newest first
- Clear "New document" action at the top
- Tabs or filters for "Owned by me" and "Shared with me"
- Each row shows title, owner, last modified
- Shared documents show who shared them

## Editor

- Title at the top, editable inline, defaults to "Untitled document"
- Toolbar pinned above the page: bold, italic, underline, heading style, bullet and numbered lists
- Active formatting is highlighted in the toolbar
- Content sits on a centered, page-like column with comfortable width
- Keyboard shortcuts: Ctrl+B, Ctrl+I, Ctrl+U
- Autosave with a status next to the title ("Saving...", "Saved")

## Sharing

- Share button at the top right of the editor
- Dialog: add a person, choose Editor or Viewer, list of people who have access with their level
- Owner is shown first and cannot be removed
- Viewers see content with the toolbar hidden or disabled and a "view only" indicator

## Import and export

- Opening a file creates a new document rather than modifying an existing one
- Export (download as Markdown or PDF) lives in a File menu; stretch only

## Feedback and errors

- Failed save shows a visible, non-blocking message and keeps the user's edits
- No access shows a plain "no access" or not found page, not a crash

## Deliberately skipped

Real-time cursors, comments, suggestion mode, version history, page layout, fonts, tables, images. Mention these as cuts in the video and `SUBMISSION.md`.
